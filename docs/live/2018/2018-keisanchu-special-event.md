## 信息

22/7于主流出道一周年当天举办的活动，也是组合首次举办的收费单独公演。

活动中包含与冠名节目《22/7 計算中》联动的企划环节，节目MC三四郎也参与了演出。

安可结束后，活动公开了此前尚未分配角色的三位成员所对应的新角色：
