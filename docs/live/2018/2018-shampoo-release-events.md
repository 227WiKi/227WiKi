# :pack-bd: 2ndシングル「シャンプーの匂いがした」発売記念リリースイベント

!!! general inline end "Live信息"
    <b>活动名称:</b> 2ndシングル「シャンプーの匂いがした」発売記念リリースイベント

    --------

    <b>举办日期:</b> 2018年4月13日、4月14日

    --------

    <b>会场:</b> 池袋サンシャインシティ、イオンモール土浦

## 信息

22/7为纪念第2张单曲《シャンプーの匂いがした》发售，于2018年4月13日在池袋サンシャインシティ喷泉广场、4月14日在イオンモール土浦举行Mini Live及击掌会。活动共举行三场，分别为4月13日18:00、4月14日13:00和16:00。

三场Mini Live均演唱了该单曲收录的5首歌曲，其中《循環バス》和《人格崩壊》于4月13日首次公开演唱。
