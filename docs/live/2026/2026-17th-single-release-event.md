# :pack-bd: 17thシングル発売記念リリースイベント

!!! general inline end "Live信息"
    <b>活动名称:</b> 17thシングル発売記念リリースイベント

    --------

    <b>举办日期:</b> 2026年8月22日、10月11日、10月22日、10月24日

    --------

    <b>会场:</b> 札幌、西宫、大阪、东京（各场会场见下文）

## 信息

### 8月22日 · 札幌

22/7于2026年8月22日在北海道札幌举办第17张单曲发行纪念活动，活动分为15:00和18:00两场，内容为Mini Live及参加成员全员的送别会。

会场为COCONO SUSUKINO 3F 屋内広場。出演成员为相川奈央、麻丘真央、天城莎莉、河瀬詩、椎名桜月、月城咲舞、望月りの。

### 10月11日 · 兵库西宫

会场为阪急西宮ガーデンズ本館4F スカイガーデン・木の葉のステージ。

| 场次 | 开演 | 出演成员 | 内容 |
| :-- | :-- | :-- | :-- |
| 1部 | 12:00 | 折本美玲、北原実咲、黒崎ありす、橘茉奈、桧山依子、南伊織、吉沢珠璃 | Mini Live |
| 2部 | 14:00 | 1部及3部的全体14名成员 | Mini Live及送别会 |
| 3部 | 17:00 | 相川奈央、麻丘真央、天城莎莉、河瀬詩、椎名桜月、月城咲舞、望月りの | Mini Live |

### 10月22日 · 大阪

椎名桜月于14:00在タワーレコード梅田NU茶屋町店举行个人活动，包含谈话、歌唱、游戏及送别会。歌唱曲目待补。

### 10月24日 · 东京

西宫场合演的14名成员于18:00在ダイバーシティ東京 プラザ2F フェスティバル広場举行Mini Live及送别会，当天首次公开演出「純情な魔女」。

### 取消的场次

原定9月21日在イオンレイクタウンmori举行的「mori Fes」是第17张单曲的预约活动，22/7_the 3rd的演出因台风取消。
