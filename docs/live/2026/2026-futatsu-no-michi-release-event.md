    --------

    <b>举办日期:</b> 2026年4月22日

## 信息

本场活动为22/7第16张单曲[二つの道](../../songs/single/16th/index.md)的发售纪念活动，内容包括迷你Live与特典会。

三期生在本场活动中首次与既有成员共同参加发售纪念活动，新曲《蝉は夏を知らない》也在现场首次披露。
