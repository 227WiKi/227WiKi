!!! general inline end "Live信息"
    <b>Live名称:</b> ナナニジライブ

    --------

    <b>举办时间:</b> 2019年1月至12月

    --------

    <b>会场:</b> Mt.RAINIER HALL SHIBUYA PLEASURE PLEASURE

## 信息

“ナナニジライブ”是22/7于2019年每月举办一次的定期公演，共举办12场。

每期公演会安排成员个人环节，并在部分场次中设置需要成员完成的挑战企划。
