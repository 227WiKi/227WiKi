## 信息

22/7于组合结成一周年当天举办的圣诞特别活动，共举行两场。

活动前半部分为朗读环节，后半部分为Live。演出结束后，现场公开了由堀口悠纪子绘制的22/7角色SD形象，并宣布《22/7 OFFICIAL BLOG》将于次日开放。
