# :pack-bd: “22/7の日” 初Live Event

!!! general inline end "Live信息"
    <b>Live名称:</b> “22/7の日” 初Live Event

    --------

    <b>举办日期:</b> 2017年7月22日

## 信息

“22/7の日” 初Live Event是22/7首次举办的Live活动。

活动中首次披露了原创曲《僕は存在していなかった》和《地下鉄抵抗主義》。演出同时包含由成员进行动作捕捉的角色Live，以及成员本人的Real Live。

活动最后宣布首张单曲《僕は存在していなかった》将于2017年9月20日发售，并公开了动画化决定。此前尚未公开形象的凉花萌、高辻丽、武田爱奈也在本次活动中首次亮相。
