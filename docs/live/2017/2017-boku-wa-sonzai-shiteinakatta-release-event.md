    --------

    <b>举办日期:</b> 2017年9月21日

    --------

    <b>会场:</b> 池袋サンシャインシティ 噴水広場

## 信息

22/7首张单曲《僕は存在していなかった》的发售纪念活动。

活动中首次披露了由11名成员共同演唱的歌曲《11人が集まった理由》。这也是组合首次在开放空间举办Live，并在演出后举行了首次击掌会。
